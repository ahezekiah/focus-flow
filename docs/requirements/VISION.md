# Vision - FocusFlow:

It's an app that will help you **focus in a environment where you can create and plan habits by motivating you to complete them in a certain time frame.**

**Our app motivates the user to create meaningful goals, within their timeframe through accountability by creating a network of responsibility where users will report and congratulate each other on sucesses and failures, whilst using streaks to keep them coming back for more. This app also provides a themed experience with layered sounds and music to provide more focus than a single track can provide.**
