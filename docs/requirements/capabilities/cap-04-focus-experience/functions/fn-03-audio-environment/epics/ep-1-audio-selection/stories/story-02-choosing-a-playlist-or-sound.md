# Story-02: Choosing a Playlist or Sound

## User Story

**As a** User,
**I want** to choose a playlist or sound during session setup
**so that** I can personalize my focus environment.

## Acceptance Criteria

- User can select from built-in playlists or individual ambient sounds
- Volume for each selected sound is adjustable

## Given / When / Then

**Given** a user is setting up a session
**When** they select "Rain" from the ambient sound list
**Then** rain sound begins playing at the default volume for that session.

**Given** a user is in a session
**When** they move the slider for the "Rain" volume level
**Then** the rain sound plays quieter.
