# Story-01: Browse Music and Default Themes

## User Story
**As a** Designer,
**I want** create default themes and allow users to browse music
**so that** users are engagesd and curious when they enter FocusFlow

## Acceptance Criteria
- Selecting a theme applies it to the current session
- User can choose from default themes/music or browse for other themes/music

## Given / When / Then
**Given** a new user has not yet selected a theme
**When** they open the music/ambience page
**Then** they see a list of default themes including rain, café, fireplace, ocean, forest, and thunder.

**Given** a user is viewin the Music & Ambience page
**When** they select a default theme or browse for another theme/music option
**Then** the selected theme is applied to the current session.
