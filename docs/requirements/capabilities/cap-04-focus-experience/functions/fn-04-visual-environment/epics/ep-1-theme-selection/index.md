# Ep-1: Theme Selection

## Overview
A theme sets both the visuals and the ambient audio for a session, so choosing one is the fastest way to make the workspace feel immersive. This epic covers the user-side act of picking a theme and having it applied to the running session.

## Acceptance Criteria
- User can select a saved or default theme before starting a session
- Theme choice affects both visuals and background audio
- Theme selection is saved with the session record
