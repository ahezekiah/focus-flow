# Story-01: Set Up a Task

## User Story
**As a** User,
**I want** to set up a task
**so that** I can track individual work items within a project.

## Acceptance Criteria
- Task can be created, edited, completed, and deleted

## Given / When / Then
**Given** a user has an existing project
**When** they create a new task and assign it to that project
**Then** the task appears under the project's task list.
