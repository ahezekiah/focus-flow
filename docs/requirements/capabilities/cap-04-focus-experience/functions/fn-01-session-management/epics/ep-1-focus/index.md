# Ep-1: Focus

## Epic-Level User Story
**As a** User,
**I want** to focus on my work
**so that** I can be productive without distraction from switching between apps.

## Acceptance Criteria
- User can begin a distraction-free work environment from a single workspace
- Focus mode combines timer, task context, and audio in one place
- User's attention stays within the app during a session (minimal focus screen)

## Given / When / Then
**Given** a user wants to focus on their work
**When** they enter a focus session
**Then** they are placed into a minimal, distraction-free work environment combining their task, timer, and chosen audio.
