# Story-02: Starting a Session

## User Story
**As a** User,
**I want** to start a session
**so that** I can begin tracking my focused work time.

## Acceptance Criteria
- "Start Focus Session" button is accessible from the dashboard
- Starting a session begins the countdown timer immediately
- Session can be started

## Given / When / Then
**Given** a user has completed session setup
**When** they tap "Start"
**Then** the countdown timer begins and the session status is marked "in progress".

## Given / When / Then
**Given** the user is viewing their main dashboard screen
**When** they look at the session configuration panel
**Then** the Start Focus Session button must be visible, enabled, and interactive

## Given / When / Then
**Given** the session start button is visible 
**When** the user selects the Session start button
**Then** the session is started
