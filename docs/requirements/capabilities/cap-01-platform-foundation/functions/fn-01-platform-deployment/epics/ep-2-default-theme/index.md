# Ep-1: Default Theme

## Overview

A designer authors the default theme so that every user — including those who haven't chosen anything yet — has a curated visual and ambient environment on their first session.

## Acceptance Criteria

- Default theme includes both a visual style and an associated ambient sound set
- Default theme is saved and reusable across sessions
