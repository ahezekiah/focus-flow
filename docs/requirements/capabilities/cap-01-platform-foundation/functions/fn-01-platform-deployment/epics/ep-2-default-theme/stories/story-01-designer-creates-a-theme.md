# Story-01: Designer Creates a Theme

## User Story
**As a** Designer,
**I want** to create a theme
**so that** users have a curated visual and audio environment to choose from.

## Acceptance Criteria
- Theme includes both a visual style and an associated ambient sound set
- Theme is saved and reusable across sessions
- Theme appears in the user's theme selection list
- Theme can be previewed before being applied

## Given / When / Then
**Given** a designer has created a "Rainy Café" theme
**When** a user opens the theme selector
**Then** the user sees a preview of the visuals and hears a sample of the ambient sound.
