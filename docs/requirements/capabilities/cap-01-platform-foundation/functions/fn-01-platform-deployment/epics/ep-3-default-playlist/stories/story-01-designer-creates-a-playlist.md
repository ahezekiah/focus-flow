# Story-01: Designer Creates a Playlist

## User Story

**As a** Designer,
**I want** to create a playlist
**so that** when the customer enters the experience they are interested and/or curious.

## Acceptance Criteria

- A playlist exists and is functional

## Given / When / Then

**Given** the default playlist has song 1, 2, 3
**When** they enter the system
**Then** the default playlist plays songs 1, 2, 3.
