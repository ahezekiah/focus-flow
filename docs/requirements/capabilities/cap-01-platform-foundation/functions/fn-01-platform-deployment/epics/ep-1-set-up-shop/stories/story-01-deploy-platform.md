# Story-01: Deploy Platform

## User Story

**As a** Business Owner/Admin,
**I want** to deploy FocusFlow to production with a landing page and default content in place
**so that** visitors can reach the app and preview the themed focus experience without needing an account.

## Acceptance Criteria

- App exists and is viewable from the web.
- Placeholder text exists: "Welcome to FocusFlow! Site is a WIP, come back later!"

## Given / When / Then

**Given** the platform is accessible
**When** a user visits the FocusFlow system
**Then** they see a working landing page with the default placholder text up
