# Fn-01: Platform Deployment

## Overview
Everything needed to launch FocusFlow: deploying the app, wiring up core infrastructure (database, hosting), and shipping the default content (theme, playlist, music) that greets visitors on day one. Does not cover user-facing sign-up or login flows — those belong to [cap-02-user-onboarding](../../../cap-02-user-onboarding/index.md).

- [ep-3-default-playlist](epics/ep-3-default-playlist/index.md) — Ship the launch-day default playlist
