# Story-01: Streaks to Motivate User

## User Story
**As a** User,
**I want** to build a streak
**so that** I stay motivated to return and focus daily.

## Acceptance Criteria
- Current streak count is visible on the dashboard
- Streak increases by 1 for each day a daily goal is met
- Streak resets if a day is missed
- Longest streak is tracked separately from current streak

## Given / When / Then
**Given** a user's current streak is 3 days
**When** they complete a session meeting their daily goal today
**Then** their current streak updates to 4 days.
