# Story-01: Increase Streak

## User Story

**As a** User,
**I want** to build a streak after completing my daily session
**so that** I can see my consistency grow

## Acceptance Criteria

- Completing the daily session increases the user's streak by one

## Given / When / Then

**Given** a user has kept their streak
**When** they complete a session meeting their daily goal
**Then** their current streak updates by one
