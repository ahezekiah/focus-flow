# Ep-1: Create Playlists

## Overview
Designers curate ordered playlists that ship as the default listening experience for new users — sparking curiosity when someone first enters FocusFlow.

## Acceptance Criteria
- Songs in the playlist are playable
- New customers can hear the sound
- A playlist can be created
- Volume is controllable
- A playlist contains an ordered list of songs
