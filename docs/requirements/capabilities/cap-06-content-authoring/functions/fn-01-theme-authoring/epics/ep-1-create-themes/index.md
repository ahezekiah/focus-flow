# Ep-1: Create Themes

## Overview
Designers assemble themes that pair a visual style with an ambient sound set, then publish them so end-users can preview and apply them to focus sessions.

## Acceptance Criteria
- A theme includes both a visual style and an associated ambient sound set
- A theme is saved and reusable across sessions
- The theme appears in the user's theme selection list
- The theme can be previewed before being applied
