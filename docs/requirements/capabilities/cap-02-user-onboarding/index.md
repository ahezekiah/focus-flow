# Cap-02: User Onboarding

## Overview
Guides brand-new users from account creation to their first successful focus session, introducing the key features (sessions, projects, tasks, music, streaks) along the way.

## Business Value
Reduces time-to-first-value for new users, increases activation, and improves long-term retention by ensuring users understand FocusFlow before they abandon it.
