# Cap-02: User Onboarding

## Overview
Guides brand-new users from account creation through their first configured focus session. Onboarding is a guided walkthrough — not just a feature tour — that has the user actually pick a starter theme and playlist, create their first task, and set up their first session so that by the end they've experienced the full loop the vision promises.

This capability owns the *first-time* guided version of activities that live as general capabilities elsewhere (theme/playlist selection in [cap-04-focus-experience](../cap-04-focus-experience/index.md), streaks in [cap-05-motivation-retention](../cap-05-motivation-retention/index.md)).

## Business Value
The vision is about creating and planning habits with a themed, layered-audio experience — a new user who lands on a dashboard without ever picking a theme, playlist, or task doesn't yet understand what FocusFlow is for. Guiding them through those first choices during onboarding is what turns a sign-up into an activated user.
