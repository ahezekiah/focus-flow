# Story-01: Onboard New User

## User Story
**As a** New User,
**I want** a brief guided introduction after I register
**so that** I understand FocusFlow's key features and can start my first session quickly.

## Acceptance Criteria
- Account creation completes in under a few minutes
- Onboarding introduces sessions, projects, tasks, music, and streaks
- Onboarding ends at the user's personalized dashboard
- Returning/experienced users can skip onboarding

## Given / When / Then
**Given** a new user has just registered
**When** they log in for the first time
**Then** they are guided through a brief onboarding flow before landing on their dashboard.
