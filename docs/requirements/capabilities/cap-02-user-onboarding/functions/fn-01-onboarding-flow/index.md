# Fn-01: Onboarding Flow

## Overview
The end-to-end flow a new user follows from registration through their first configured focus session. Covers account creation and feature introduction, then walks the user through their initial theme, playlist, task, and session choices so they leave onboarding with a fully configured, ready-to-run setup.

## Epics
- [ep-1-onboard-customer](epics/ep-1-onboard-customer/index.md) — Account creation, feature introduction, and landing on the dashboard
- [ep-2-first-time-setup](epics/ep-2-first-time-setup/index.md) — Guided first choices of theme, playlist, task, and session
