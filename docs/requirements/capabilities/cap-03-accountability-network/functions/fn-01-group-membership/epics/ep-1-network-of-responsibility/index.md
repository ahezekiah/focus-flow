# Ep-1: Network of Responsibility

## Epic-Level User Story

**As a** User,
**I want** to define a network of responsibility
**so that** I have people who help hold me accountable to my focus goals.

## Acceptance Criteria

- User can create or join a group of peers that supports mutual accountability.

## Given / When / Then

**Given** a user wants accountability support
**When** they set up or join an accountability group
**Then** the group is established and all members can see each other's session activity going forward.
