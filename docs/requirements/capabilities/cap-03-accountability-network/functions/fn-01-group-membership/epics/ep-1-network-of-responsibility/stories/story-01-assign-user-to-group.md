# Story-01: Assign User to Group

## User Story

**As a** User,
**I want** to be assigned to a group
**so that** I can share my progress with accountability partners.

## Acceptance Criteria

- User can join or be added to a group
- Group membership is visible on the user's profile
- Group members can see each other's met goals

## Given / When / Then

**Given** a user has a group invite code
**When** they enter the code on the groups page
**Then** they are added as a member of that group.


**Given** a user has joined a group
**When** they view their home page
**Then** they can see the group they are a part of


**Given** a user has a goal to complete
**When** they complete this goal
**Then** other members of the group can view these completed goals
