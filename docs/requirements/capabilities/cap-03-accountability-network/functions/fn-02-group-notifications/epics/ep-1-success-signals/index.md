# Ep-1: Success Signals

## Overview

When a group member finishes a goal, the system fires a notification to the rest of the group and enables peers to send a congratulatory reaction. Together these turn a solo completion into a shared, motivating moment.

## Acceptance Criteria

- Notifications fire immediately on goal completion, which are visible to all group members and include who completed which session
- Group members can send a congratulatory reaction/message tied to that session, which appears in the group's activity feed
