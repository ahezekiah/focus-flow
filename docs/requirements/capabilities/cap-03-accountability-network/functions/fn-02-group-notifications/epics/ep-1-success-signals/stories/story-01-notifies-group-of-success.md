# Story-01: Notifies Group of Success

## User Story

**As the** System,
**I want** to notify the group of a member's success
**so that** accountability and encouragement happen automatically.

## Acceptance Criteria

- Notification fires immediately when a session is marked "completed", which is visible to all members of the relevant group

## Given / When / Then

**Given** a user completes a coding project goal
**When** the goal status changes to "completed"
**Then** all group members receive a notification stating the goal was completed.
