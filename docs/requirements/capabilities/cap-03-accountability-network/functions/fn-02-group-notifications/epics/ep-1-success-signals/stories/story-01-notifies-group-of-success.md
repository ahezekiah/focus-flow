# Story-01: Notifies Group of Success

## User Story
**As the** System,
**I want** to notify the group of a member's success
**so that** accountability and encouragement happen automatically.

## Acceptance Criteria
- Notification fires immediately when a session is marked "completed"
- Notification is visible to all members of the relevant group
- Notification includes which member completed the session and the objective/duration

## Given / When / Then
**Given** a user completes a 45-minute coding session
**When** the session status changes to "completed"
**Then** all group members receive a notification stating the session was completed.
