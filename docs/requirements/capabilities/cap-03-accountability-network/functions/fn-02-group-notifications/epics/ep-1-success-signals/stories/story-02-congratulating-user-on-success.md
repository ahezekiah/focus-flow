# Story-02: Congratulating User on Success

## User Story
**As a** Group Member,
**I want** to congratulate a peer on their success
**so that** we build accountability and motivation within the group.

## Acceptance Criteria
- Group members receive a notification when a peer completes a session
- Members can send a congratulatory reaction or message
- Congratulations are visible in the group's activity feed

## Given / When / Then
**Given** a group member completes a focus session
**When** another member views the group activity feed
**Then** they can react with a congratulatory response tied to that session.
